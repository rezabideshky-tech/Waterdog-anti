# 🚗 جاده‌باز — بازی ایرانی رانندگی (Godot 4)

یک بازی کامل رانندگی دو‌بعدی با حال‌وهوای «شوفر»: ماشین‌های ایرانی، جاده‌های ایران،
فیزیک واقعی سربالایی و پرش، گاراژ و ارتقا، فروشگاه، گردونهٔ شانس، ماموریت و مسابقهٔ رکورد.

ساخته‌شده برای **گودوت ۴.۴** (با ۴.۳ هم بالا می‌آید) و برای **موبایل** تنظیم شده است.

## 🚀 چطور باز کنم و APK بگیرم؟

### ۱) گودوت را نصب کن
از [godotengine.org/download](https://godotengine.org/download) نسخهٔ **Godot 4.4** (یا ۴.۳) را
برای ویندوز/لینوکس دانلود کن. نسخهٔ استاندارد (نه .NET) کافی است.

### ۲) پروژه را باز کن
`Godot` → `Import` → فایل `project.godot` این پوشه را انتخاب کن → **Import & Edit**.
اولین اجرا کمی طول می‌کشد چون موتور، تصویرها را import می‌کند. برای تست سریع روی کامپیوتر
کلید **F5** را بزن.

### ۳) APK اندروید
1. در گودوت: `Editor` → `Manage Export Templates` → **Download and Install** (یک‌بار).
2. **Android SDK** لازم است. ساده‌ترین راه: [Android Studio](https://developer.android.com/studio) را نصب کن
   (SDK و build-tools و platform-tools را نصب می‌کند)، بعد در گودوت:
   `Editor` → `Editor Settings` → `Export` → `Android`:
   - `Android SDK Path` → مثلاً `C:\Users\<user>\AppData\Local\Android\Sdk`
   - `Debug Keystore` → مسیر کلید دیباگ (پایین را ببین)
3. ساخت کلید دیباگ (یک‌بار، در CMD):
   ```
   keytool -keyalg RSA -genkeypair -alias androiddebugkey -keypass android -keystore debug.keystore ^
     -storepass android -dname "CN=Android Debug,O=Android,C=US" -validity 9999 -deststoretype pkcs12
   ```
   فایل ساخته‌شده (`debug.keystore`) را در مسیر `Debug Keystore` بده و رمزها را
   `android` / `android` بگذار.
4. حالا: `Project` → `Export...` → از فهرست **Android** را انتخاب کن →
   مسیر خروجی `build/jadebaz.apk` است → دکمهٔ **Export Project** →
   تیک «Export With Debug» را برای تست بزن (برای نسخهٔ نهایی بردار تا از release template بسازد).

> اگر گودوت پیام «Android build template» داد، برای این پروژه **لازم نیست**
> (`gradle_build/use_gradle_build = false` است) و با همان قالب‌های پیش‌ساخته APK می‌گیرد.
> برای امضای نسخهٔ نهایی، یک keystore واقعی بساز و در بخش `Keystore` همان پنجرهٔ Export بده.

### ۴) تست روی گوشی
گوشی را با کابل وصل کن (USB Debugging روشن) و در گودوت دکمهٔ ▶ (One-click Deploy) را بزن.

## 🎛 تنظیم و شخصی‌سازی

- **قدرت، سرعت، بنزین، قیمت ماشین‌ها:** `src/autoload/Game.gd` → `CARS`
- **سختی مسیرها (تپه‌ها، زبری، طول، جایزه):** `Game.gd` → `LEVELS`
- **فیزیک (گرانش، گشتاور، اصطکاک، نیترو):** `src/car/CarRig.gd` بالای فایل
- **رنگ دکمه‌ها و تم:** `src/ui/UI.gd`
- **بازسازی تصویرها:** در پوشهٔ `tools`:
  ```
  npm install
  node gen_assets.mjs     # همهٔ تصویرها
  node specs.mjs          # هندسهٔ چرخ‌ها از روی تصویرها
  node icons_sheet.mjs    # پیش‌نمایش آیکون‌ها در docs/
  node preview_car.mjs    # پیش‌نمایش ماشین‌ها در docs/cars-rig.png
  ```

> پوشهٔ `tools/node_modules` را داخل زیپ/گیت لازم نداری؛ فقط برای بازسازی تصویرها است.

## 🔧 اگر مشکلی پیش آمد

- **حروف فارسی جدا نمایش داده می‌شود:** فونت‌ها در `assets/fonts/` هستند؛ در
  `src/ui/UI.gd` مسیر `FONT_PATH` را چک کن.
- **سرعت کم روی گوشی‌های ضعیف:** در تنظیمات بازی «کیفیت بالا» را خاموش کن؛ همچنین
  تعداد سکه‌های همزمان با پنجرهٔ فعال‌سازی در `src/world/Terrain.gd` کنترل می‌شود.
- **خطای Android SDK:** مسیر SDK و کلید دیباگ را در Editor Settings کامل کن.
- **بازی سنگین است؟** در `project.godot` → `rendering/textures/vram_compression/import_etc2_astc=true`
  فعال است؛ برای APK کوچک‌تر می‌توانی بافت‌ها را با فرمت فشرده import کنی.

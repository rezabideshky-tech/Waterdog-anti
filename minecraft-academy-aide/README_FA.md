# مکعب‌آموز — پروژهٔ اندروید فارسی برای AIDE

یک اپ آموزشی آفلاین و فارسی برای یادگیری نکته‌های ماینکرفت. رابط کاربری و تصویرسازی مکعبی داخل خود برنامه رسم شده‌اند؛ هیچ کتابخانه یا فایل تصویری خارجی لازم نیست.

## ویژگی‌ها

- ۸ درس مرحله‌ای دربارهٔ شب اول، ابزارسازی، خانه، کشاورزی، معدن، نبرد، ردستون و اِنْد
- آزمون کوتاه برای هر درس؛ پاسخ درست ۵۰ XP می‌دهد
- ذخیرهٔ پیشرفت و نشان‌ها روی همان دستگاه
- دانشنامهٔ فارسی با جست‌وجوی واژه‌ها
- رابط راست‌چین و تصویرسازی مکعبی اختصاصی؛ بدون نیاز به اینترنت
- بدون وابستگی به کتابخانه‌های جانبی

## ساخت APK با AIDE روی موبایل

1. فایل ZIP را در گوشی از حالت فشرده خارج کن.
2. در AIDE گزینهٔ **Open existing project / بازکردن پروژهٔ موجود** را بزن و پوشهٔ `minecraft-academy-aide` را انتخاب کن؛ همان پوشه‌ای که `AndroidManifest.xml` و `project.properties` را دارد.
3. اگر AIDE دربارهٔ پلتفرم پرسید، Android API 28 یا یک API جدیدترِ نصب‌شده را انتخاب کن.
4. دکمهٔ **Run** را بزن تا پروژه ساخته و روی گوشی نصب شود. برای گرفتن فایل نصب، از منوی AIDE گزینهٔ Build/Export APK را انتخاب کن (نام منو بسته به نسخهٔ AIDE کمی فرق می‌کند).

این پروژه از قالب سادهٔ Java/Android استفاده می‌کند و برای ساخت مستقیم در AIDE به Gradle یا کتابخانهٔ آنلاین نیاز ندارد. حداقل نسخهٔ اندروید Android 5.0 (API 21) است.

## ساخت APK از GitHub

در مخزن کامل GitHub، پوشهٔ `android-build` و workflow با نام **Build Minecraft Academy APK**، همین سورس را با Gradle و Android SDK می‌سازند. پس از Push سورس به شاخهٔ کاری، در GitHub بخش **Actions** را باز کن و artifact با نام `MinecraftAcademy-debug-apk` را دانلود کن. این APK برای نصب و آزمایش امضای debug دارد.

## حریم خصوصی و نام تجاری

برنامه آفلاین است و هیچ داده‌ای را به سرور نمی‌فرستد؛ پیشرفت فقط با SharedPreferences روی همین دستگاه نگهداری می‌شود. این یک راهنمای آموزشی غیررسمی است؛ Minecraft و نام‌ها و نشان‌های مرتبط، متعلق به صاحبان حقوقشان هستند و این پروژه وابستگی یا تأیید رسمی ندارد.

# 🛡️ AntiAdvertising — پلاگین ضد تبلیغات حرفه‌ای برای PocketMine-MP API 5

پلاگین **AntiAdvertising** یک سیستم کامل، هوشمند و قابل تنظیم برای جلوگیری از انواع تبلیغات (آی‌پی، دامنه، لینک دیسکورد، شبکه‌های اجتماعی و جملات تبلیغاتی) در سرورهای **Minecraft Bedrock (PocketMine-MP API 5)** است.

---

## ✨ امکانات و ویژگی‌ها

- **پشتیبانی کامل از PocketMine-MP API 5 (`api: 5.0.0`)**
- **بررسی تمامی بخش‌های سرور:**
  - 💬 چت عمومی (`PlayerChatEvent`)
  - 📩 دستورات پیام خصوصی و عمومی (`CommandEvent`: مانند `/msg`, `/tell`, `/w`, `/whisper`, `/pm`, `/r`, `/me`, `/say`, `/mail` و...)
  - 🪧 تابلوها (`SignChangeEvent` — شامل تشخیص تکه کردن آدرس در چند خط تابلو)
  - 📖 کتاب‌ها (`PlayerEditBookEvent` — بررسی عنوان و صفحات کتاب)
  - 🔨 تغییر نام آیتم‌ها (`InventoryTransactionEvent` و `PlayerItemHeldEvent`)
- **موتور تشخیص هوشمند ضد دور زدن (Anti-Obfuscation):**
  - تشخیص اعداد فارسی و عربی (`۱۹۲.۱۶۸.۱.۱:۱۹۱۳۲`)
  - تشخیص حروف فاصله‌دار (`p l a y . e x a m p l e . i r` یا `1 9 2 . 1 6 8 . 1 . 1`)
  - تشخیص جایگزین‌های نقطه مانند `(dot)`، `[.]`، `نقطه`، `دات`، `•` و...
  - حذف کدهای رنگی ماینکرافت (`§a`, `&c`) و کاراکترهای نامرئی قبل از بررسی
- **سیستم اخطار و مجازات مرحله‌ای خودکار (قابل تنظیم در `config.yml`):**
  1. **اخطار ۱:** حذف تبلیغ + اخطار به بازیکن (`warn`)
  2. **اخطار ۲:** سایلنت موقت خودکار ۵ دقیقه‌ای (`mute`)
  3. **اخطار ۳:** اخراج از سرور (`kick`)
  4. **اخطار ۴:** بن موقت ۲۴ ساعته یا دائم (`tempban` / `ban` / اجرای دستور کنسول دلخواه)
- **لیست سفید (Whitelist) پویا:**
  - امکان تعریف دامنه، آی‌پی، لینک دیسکورد و کانال تلگرام سرور خودتان تا مسدود نشوند (قابل ویرایش مستقیم از داخل بازی با دستور `/antiad whitelist`).
- **گزارش لحظه‌ای به ادمین‌ها و ذخیره لاگ:**
  - ارسال هشدار جزئیات تبلیغ به ادمین‌های آنلاین و ثبت در فایل `plugin_data/AntiAdvertising/detections.log`.

---

## 📦 نحوه نصب

1. فایل آماده **`AntiAdvertising.phar`** موجود در همین ریپازیتوری را دانلود کنید.
2. آن را در پوشه `plugins/` سرور PocketMine-MP 5 خود قرار دهید.
3. سرور را ری‌استارت کنید.
4. فایل تنظیمات در مسیر `plugin_data/AntiAdvertising/config.yml` ساخته می‌شود. آدرس سرور و دیسکورد خودتان را در بخش `whitelist` وارد کرده و دستور `/antiad reload` را بزنید.

---

## ⌨️ دستورات (Commands)

دستور اصلی: `/antiad` (یا خلاصه: `/aa`)

| دستور | توضیح |
|---|---|
| `/antiad status` | نمایش وضعیت بخش‌های فعال و آمار پلاگین |
| `/antiad reload` | بازخوانی فایل `config.yml` بدون نیاز به ری‌استارت سرور |
| `/antiad warns <player>` | مشاهده تعداد و تاریخچه اخطارهای یک بازیکن |
| `/antiad clearwarns <player>` | پاک کردن اخطارها و رفع محدودیت‌های بازیکن |
| `/antiad unmute <player>` | خارج کردن بازیکن از حالت سایلنت (Mute) |
| `/antiad whitelist list` | مشاهده لیست دامنه‌ها و آی‌پی‌های مجاز |
| `/antiad whitelist add <domain/ip>` | افزودن دامنه یا آی‌پی به لیست سفید |
| `/antiad whitelist remove <domain/ip>` | حذف دامنه یا آی‌پی از لیست سفید |
| `/antiad test <text>` | تست کردن یک متن برای بررسی عملکرد تشخیص‌دهنده تبلیغات |

## 🔐 دسترسی‌ها (Permissions)

| پرمیشن | پیش‌فرض | توضیح |
|---|---|---|
| `antiadvertising.admin` | `op` | دسترسی کامل به دستورات مدیریتی `/antiad` |
| `antiadvertising.bypass` | `op` | معافیت از بررسی تبلیغات (مخصوص ادمین‌ها) |
| `antiadvertising.notify` | `op` | دریافت هشدار لحظه‌ای در چت هنگام تلاش بازیکنان برای تبلیغ |

## 🛠️ ساخت مجدد فایل `.phar`

در صورت ویرایش سورس‌کد، می‌توانید با یکی از دو روش زیر فایل `AntiAdvertising.phar` را بسازید:

```bash
# با پایتون:
python3 scripts/build_phar.py

# یا با PHP CLI:
php -d phar.readonly=0 scripts/build_phar.php
```

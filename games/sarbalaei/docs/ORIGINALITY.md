# Originality rules (clean room)

Sarbalaei takes its genre (side-view hill climbing with physics) and nothing else from other
games. The rules below apply to every commit.

1. **No assets from other games.** No images, sounds, fonts, or level data from any other
   game are used, copied, or extracted. No APK from another game is opened.
2. **No copied interface.** Screen layouts, button arrangements, icons, and HUD design are
   designed for this project, not copied from screenshots of other games.
3. **No copied names or branding.** The game is not named after or styled after another title.
   Vehicle names are original. Real manufacturers' models are not used as names or art.
4. **Original art.** Art is drawn in code or produced for this project, and the source is noted
   in `LICENSES.md`.
5. **Check the name.** Before a public release, search the trademark register for the name
   "سربالایی" in the target markets.
6. **Review.** A change that adds an asset or a name is reviewed against these rules in its
   pull request.

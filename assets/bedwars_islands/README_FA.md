# ARVAN GAMING — چهار جزیرهٔ ورود به بدوارز

چهار مدل مستقل، قابل‌ویرایش و انیمیشن‌دار برای لابی بدوارز. هر جزیره یک تخت تیمی دارد و تعداد جنگجوها برابر تعداد اعضای همان مود است.

| مود | طرح | رنگ | شخصیت‌ها |
| --- | --- | --- | --- |
| SOLO | آخرین بازمانده | آبی | یک جنگجوی تنها با شمشیر و بلوک |
| DOUBLES | حمله و دفاع | سبز | یک سازنده و یک نگهبان تخت |
| TRIPLES | سه نقش، یک تیم | بنفش | مهاجم، سازنده و مدافع؛ سکوی کوچک الماس |
| SQUADS | قلعهٔ چهار نفره | طلایی | فرمانده، سازنده، مدافع و کماندار روی برجک |

همهٔ مدل‌ها جزیرهٔ سنگی با سطح چمنی، پل پشمی کوتاه، تخت رنگی، دفاع نیمه‌باز، ژنراتور نمایشی، پرچم تعداد نفرات و پلاک ARVAN GAMING دارند. عرض سطح اصلی ۲۴ واحد Blockbench، معادل ۱٫۵ بلوک است. پل به سمت جلو امتداد دارد؛ عمق کلی حدود ۱٫۸ بلوک و ارتفاع پرچم از پایین جزیره حدود ۱٫۹ بلوک است. شخصیت‌ها و وسایل، بخش‌های کوچک یک مدل نمایشی واحد هستند، نه بازیکن یا آیتم واقعی.

## محتویات ZIP

- `models/`: چهار فایل `.bbmodel` با تکسچر ۵۱۲×۵۱۲ توکار، PNG مستقل، هندسهٔ Bedrock، انیمیشن، تصویر و GIF پیش‌نمایش.
- `ArvanBedwarsIslands_RP.zip`: ریسورس‌پک آمادهٔ قرار گرفتن در resource_packs سرور.
- `ArvanBedwarsIslands.mcpack`: همان پک برای واردکردن در کلاینت؛ به‌تنهایی موجودیت نمی‌سازد.
- `plugins/ArvanBedwarsIslands.phar`: پلاگین کامپایل‌شدهٔ PocketMine برای ساخت، حذف و کلیک روی NPCها.
- `plugin/ArvanBedwarsIslands/`: سورس همان پلاگین؛ همراه PHAR نصب نکنید.
- `PREVIEW.jpg`: تصویر هر چهار مدل، رندرشده از هندسهٔ واقعی.
- `resource_packs.example.yml`: نمونهٔ تنظیمات؛ فایل تنظیمات فعلی سرور را با آن جایگزین نکنید.

## ویرایش در Blockbench

از File → Open Model فایل `.bbmodel` هر پوشه را باز کنید. در تب Animate، انیمیشن `lobby_idle` را پخش کنید. انیمیشن شامل حرکت شناور ملایم جزیره، حرکت پرچم و دست و سر جنگجوها، چرخش منابع نمایشی و تغییر اندازهٔ آخرین بلوک پل است. همهٔ بخش‌ها گروه‌بندی شده و جداگانه قابل ویرایش‌اند. چرخه ۴ ثانیه است و بدون پرش تکرار می‌شود.

## نصب روی PocketMine-MP 5

پیش‌نیاز: **PocketMine-MP 5 با API 5.1.3 یا جدیدتر در شاخهٔ 5 و افزونهٔ Customies سازگار با سرور شما**. خود PocketMine و Customies در ZIP قرار ندارند. مرجع Customies: https://github.com/CustomiesDevs/Customies

1. از دنیاها و تنظیمات بکاپ بگیرید و سرور را کامل متوقف کنید.
2. اگر Customies نصب نیست، نسخهٔ سازگار آن را جداگانه نصب کنید.
3. فایل `plugins/ArvanBedwarsIslands.phar` را در `plugins/` سرور کپی کنید. DevTools لازم نیست.
4. فایل `ArvanBedwarsIslands_RP.zip` را در `resource_packs/` سرور بگذارید؛ نه ZIP بزرگ مجموعه را.
5. در **فایل موجود** `resource_packs/resource_packs.yml` این پک را به `resource_stack` اضافه کنید و پک‌های قبلی را نگه دارید:

```yaml
force_resources: true
resource_stack:
  # پک‌های قبلی شما نیز باید باقی بمانند
  - ArvanBedwarsIslands_RP.zip
```

6. سرور را روشن کنید، دوباره وارد بازی شوید و دانلود پک را قبول کنید.
7. با OP در نقطهٔ موردنظر بایستید و دستور همان مود را بزنید:

```text
/bwislands spawn solo
/bwislands spawn doubles
/bwislands spawn triples
/bwislands spawn squads
/bwislands remove
```

جزیره در محل شما با ارتفاع اولیهٔ ۰٫۴ بلوک بالاتر قرار می‌گیرد تا حالت معلق داشته باشد؛ چند قدم کنار بروید تا دیده شود. مقدار `spawn-height-offset` در تنظیمات، ارتفاع NPCهای بعدی را تغییر می‌دهد. جهت نگاه افقی شما، جهت قرارگیری مدل است. دستور remove فقط نزدیک‌ترین NPC همین بسته را تا فاصلهٔ ۶ بلوک حذف می‌کند. مدل‌ها با ذخیرهٔ عادی چانک ذخیره می‌شوند؛ پلاگین و Customies باید هنگام بازشدن دوبارهٔ دنیا نیز نصب باشند.

## مهم: اتصال کلیک به ورود واقعی مود

کلیک و ضربه روی NPC پشتیبانی می‌شود، اما **نام پلاگین بدوارز و دستور ورود یا آدرس سرورهای شما مشخص نیست**. بنابراین مسیرها به‌صورت پیش‌فرض `none` هستند و تا زمان تنظیم، کلیک فقط پیام «متصل نشده» نشان می‌دهد. سیستم مسابقه، تیم‌بندی و صف ورود در این بسته ساخته نشده است.

پس از اولین اجرا فایل زیر ساخته می‌شود:

`plugin_data/ArvanBedwarsIslands/config.yml`

برای هرکدام از `solo`، `doubles`، `triples` و `squads` یکی از این روش‌ها را تنظیم کنید:

- `action: command`: دستور واقعی ورودِ پلاگین بدوارز خود را در `command` بنویسید، بدون `/` اول آن. دستور با دسترسی خود بازیکن اجرا می‌شود، نه کنسول. جای‌نگهدارهای `{player}` و `{mode}` پشتیبانی می‌شوند.
- `action: transfer`: آدرس واقعی سرور را در `address` و پورت را در `port` بنویسید. برای شبکه‌هایی که انتقال داخلی پروکسی دارند، در صورت نیاز از دستور پلاگین شبکه و روش command استفاده کنید.
- `action: none`: فقط نمایش مدل و پیام متصل‌نبودن.

بعد از ویرایش تنظیمات، سرور را ری‌استارت کنید. پورت، آدرس یا دستور ساختگی برای مودها قرار داده نشده است. مجوز استفادهٔ بازیکنان `arvanislands.use` و مجوز مدیریت `arvanislands.admin` است. برای جلوگیری از اجرای تکراری با لمس موبایل، هر بازیکن یک ثانیه محدودیت کلیک دارد.

## شناسه‌ها

```text
arvan:bw_solo_island
arvan:bw_doubles_island
arvan:bw_triples_island
arvan:bw_squads_island
```

این شناسه‌ها با مدل‌های لابی و رول‌پلی قبلی مخزن متفاوت‌اند. پک موجودیت‌های وانیلا را جایگزین نمی‌کند. اگر در پلاگین خودتان این شناسه‌ها را ثبت می‌کنید، پلاگین نمونه را هم‌زمان فعال نکنید.

## حدود و بررسی‌ها

- تخت، پل، شمش‌ها، صندوق و الماس داخل مدل صرفاً تزئینی‌اند؛ بلوک قابل تخریب یا منبع قابل برداشت نیستند.
- انیمیشن‌ها سمت کلاینت اجرا می‌شوند و فاز آن‌ها ممکن است برای هر بازیکن متفاوت باشد.
- هندسه، ارجاعات گروه‌ها، تعداد شخصیت‌ها و تخت، UVها و تکرار صحیح انیمیشن بررسی شده‌اند. سینتکس PHP و امضای SHA-256 فایل PHAR نیز بررسی شده است.
- تست زندهٔ این نسخه روی PocketMine و کلاینت Bedrock در این محیط انجام نشده؛ ابتدا روی سرور تست خود امتحان کنید.

## بازتولید از سورس

Python 3.10+ و PHP 8.1+:

```sh
python -m pip install -r requirements.txt
php -d phar.readonly=0 build_phar.php
python generate.py --gifs
python -m unittest test_assets.py
```

بدون `--gifs` ساخت سریع‌تر است. برای فقط بازسازی ZIP از فایل‌های موجود، `python generate.py --bundle-only` اجرا کنید.

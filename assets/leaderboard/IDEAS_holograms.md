# 💠 ۲۰ ایدهٔ اختصاصی «هولوگرام لیدربورد» — ساخته‌شده روی پلاگین‌های خودت

> این ایده‌ها بر اساس همان چیزهایی نوشته شده که **همین حالا روی گیت‌هاب خودت هست**:
> `ArvanLobby` (NPC دوئوس/سکای‌بلاک/کامیون + لیست انتظار)، `BedWarsBattlePass` (سطح و XP)،
> `ArvanVehicles` (رانندگی و باربری)، `ArvanPackGuard` و `ArvanLeaderboards` (kills/wins/beds/deaths/points).
> پس هر ایده «قابل اجرا با همان کد و همان config» است — نه خیال‌بافی.

---

## ۰) چرا هولوگرام، وقتی مدل بلوکی هم داریم؟

| لایه | کارش | مثال |
| --- | --- | --- |
| **مدل** (`.bbmodel` / Customies) | زیبایی، تم، جذب چشم | تخته‌سنگ کدو، پروژکتور، تخت خون‌آشام |
| **هولوگرام متنی** (nametag / floating text) | **اطلاعات زنده** — آمار، رتبه، تایمر، صف | «🥇 Ali — ۲۴۱ برد» |

**قانون طلایی:** هولوگرام روی مدل می‌نشیند (چند بلوک بالاتر از نگین امضای مشترک)، نه جای آن.
مدل می‌فروشد، هولوگرام **نگه می‌دارد** (بازیکن برای دیدن رتبهٔ خودش برمی‌گردد).

---

## ۱) 🎨 سیستم طراحی واحد هولوگرام (Design System)

هر هولوگرام **۵ لایه** دارد — همه‌جا یکسان، تا کل لابی یک هویت واحد داشته باشد:

```
§l§6⚔ BEDWARS TOP KILLS          ← ۱) سرتیتر: طلایی ضخیم + ایموجی
§7━━━━━━━━━━━━━━━          ← ۲) خط جداکننده (یا نوار پیشرفت)
§e🥇 §fAli §8| §a241 §7kill   ← ۳) ردیف‌ها: نام سفید، عدد سبز، واحد خاکستری
§7🥈 §fSara §8| §a198 §7kill
§8🥉 Reza | 155 kill
§7━━━━━━━━━━━━━━━
§8آخرین به‌روزرسانی ۱۲ ثانیه پیش   ← ۴) فوتر: اعتماد و زنده‌بودن
§7رقم خودت را با §e/rank §7ببین     ← ۵) دعوت به تعامل
```

**قواعد سخت‌گیرانه (رعایتشان = حرفه‌ای دیده شدن):**
- حداکثر **۳۲ کاراکتر** هر خط (بدراک در دنیای NPC بلند‌تر از این می‌بُرد).
- **۵ تا ۷ ردیف**؛ بیشتر از آن روی موبایل ناخوانا می‌شود.
- رنگ‌ها: `§6` طلا / `§b` فیروزه / `§a` سبز (عدد) / `§f` سفید (نام) / `§8` خاکستری (متادیتا) / `§c` قرمز (خطر).
- ایموجی‌ها ثابت: `👑 🥇 🥈 🥉 ⚔️ 🛏️ 🎯 🔥 ⏱️ 🧪 💰 👻 🎃`
- همیشه **یک عدد سبز** در هر ردیف؛ چشم روی رنگ سبز قفل می‌شود.

## ۳) ✨ افکت‌های متنی که فقط با `§` می‌شود ساخت (بدون هیچ مودل و پکی)

| افکت | نمونه | چطور |
| --- | --- | --- |
| **نوار پیشرفت** | `§a▉▉▉▉▉▉▉░░░ §7۷۰٪` | ساخت رشته در PHP: `str_repeat("▉", $n)` |
| **شمارش پرشی** | عدد از ۰ تا مقدار واقعی در ۱ ثانیه | آپدیت هر ۲ تیک، ۸ فریم |
| **چشمک رتبهٔ ۱** | `§e§l🥇` → `§6§l🥇` هر ۵۰۰ms | toggle رنگ در حلقهٔ refresh |
| **تایپ‌شدن MVP** | `§fA` → `§fAl` → `§fAli` | substring با شمارندهٔ زمانی |
| **فلش رکورد** | کل خط‌ها یک‌بار سفید می‌شوند | یک فریم `§f§l` روی همهٔ خطوط |
| **نردبان رتبه** | `§a▲۲` / `§c▼۱` نسبت به دیروز | نگه‌داشتن رتبهٔ دیروز در `stats.yml` |
| **سرتیتر تپنده** | طلایی ↔ نارنجی | دو رنگ لوپ |

> همهٔ این‌ها فقط `setNameTag()` / floating text + یک تسک هر ۲۰ تیک است — **بدون Customies، بدون پک تازه**. روی هر سروری کار می‌کند.

## ۴) 🧩 نمونهٔ `config.yml` — دقیقاً به سبک پلاگین‌های خودت

```yaml
# ArvanHolograms — به سبک npcs: خودت در ArvanLobby و ArvanLeaderboards
holograms:
  bw_trio:
    model: hw_top                 # مدل میزبانی که هولوگرام رویش می‌نشیند
    offset: 4.5                   # چند بلوک بالای نگین امضای مشترک
    rotate: 10                    # چرخش خودکار بین ستون‌ها (ثانیه)، 0 = خاموش
    tap_cycle: true               # با ضربه روی مدل، ستون عوض شود
    tracks: [kills, wins, beds]
    header: "§l§6⚔ BEDWARS §eLIVE"
    footer: "§8آخرین به‌روزرسانی: §7{ago} §8| §7رتبهٔ خودت: §e/rank"
    lines: 5
  battlepass:
    model: hologram
    offset: 4.0
    source: battlepass            # از پلاگین BedWarsBattlePass می‌خواند
    header: "§l§b🧪 BATTLE PASS §f— §eSEASON 1"
    body: "levels"
    footer: "§8{players} بازیکن این فصل — جایزهٔ سطح بعدی: §a{reward}"
  skyblock_wait:
    model: arvan_skyblock_soon
    offset: 3.5
    source: lobby_waiting:skyblock   # همان waiting.yml خودت
    header: "§l§aSKYBLOCK §7— SOON"
    body: "§b{count} §7بازیکن منتظر!"
    footer: "§8Tap to join the list"
halloween:
  enabled: true
  theme: pumpkin                  # سرتیتر طلایی→نارنجی، ایموجی 🎃
  boards: [trick_or_treat, soul_counter, shame_tomb]
```

## ۶) ⚡ پیشنهاد «همین امشب» (۳ گام، بیشترین بازده)

1. **`arvan:holo_trio`** — یک مدل، سه ستون kills/wins/beds، آپدیت هر ۵ ثانیه، tap-to-cycle.
   (کمترین کد، بیشترین حسِ «سرور حرفه‌ای».)
2. **`battlepass` روی مدل هولوگرام** — چون پلاگینش را از قبل داری؛ فقط خواندن سطح.
3. **`skyblock_wait`** — همان `{count}` که در `ArvanLobby` نوشتی، روی مدل `arvan_skyblock_soon`.

بگو کدام را بسازم، کد پلاگین `ArvanHolograms` (PHP، PMMP 5، به سبک خودت) + کانفیگ + پرست‌های هنری را همین‌جا اضافه می‌کنم.

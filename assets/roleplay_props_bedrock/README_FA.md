# Arvan Gaming — ریسورس‌پک و پلاگین مدل‌های رول‌پلی

این بسته برای **PocketMine-MP 5 (API 5.1.3 یا جدیدتر در شاخهٔ 5)** آماده شده است. دو مدل سفارشی دارد: پمپ دیجیتال و جعبه مهمات. نوشته‌های ARVAN GAMING حفظ شده‌اند و درِ جعبه بدون نوشته است.

## کدام فایل را استفاده کنم؟

- **ArvanRoleplayProps_PocketMine.zip**: بستهٔ نصب سرور؛ شامل ریسورس‌پک، پلاگین کامپایل‌شدهٔ PHAR، نمونه تنظیمات، سورس پلاگین، راهنما و تصویر مدل‌ها.
- **ArvanRoleplayProps_RP.zip**: فقط ریسورس‌پک استاندارد Bedrock؛ فایل `manifest.json` در ریشهٔ ZIP است. برای پوشهٔ `resource_packs/` سرور از این فایل استفاده کنید.
- **ArvanRoleplayProps.mcpack**: همان ریسورس‌پک با پسوند قابل واردکردن در کلاینت Bedrock؛ مدل‌ها با واردکردن آن به‌تنهایی قابل اسپاون نمی‌شوند.
- **ArvanRoleplayProps.phar**: پلاگین آمادهٔ PocketMine؛ نیازی به DevTools ندارد.

**خود PocketMine، افزونهٔ Customies و فایل‌های دنیا داخل بسته نیستند.** این ZIP جایگزین کل پوشهٔ سرور نیست و نباید جایگزین تنظیمات یا پلاگین‌های موجود شود.

## نصب روی سرور

1. از تنظیمات و دنیاها بکاپ بگیرید و سرور را کامل متوقف کنید؛ از reload استفاده نکنید.
2. **Customies سازگار با نسخهٔ PocketMine خود را جداگانه نصب کنید.** اگر از قبل نصب است، نسخهٔ دوم اضافه نکنید. مرجع رسمی: https://github.com/CustomiesDevs/Customies
3. فایل `plugins/ArvanRoleplayProps.phar` را در پوشهٔ `plugins/` سرور کپی کنید.
4. فایل `resource_packs/ArvanRoleplayProps_RP.zip` را در پوشهٔ `resource_packs/` سرور کپی کنید؛ خود ZIP باید آنجا قرار بگیرد، نه فایل ZIP بزرگ بستهٔ نصب.
5. فایل **موجود** `resource_packs/resource_packs.yml` را باز کنید و فقط نام پک را به لیست `resource_stack` اضافه کنید. پک‌های قبلی را نگه دارید:

```yaml
force_resources: true
resource_stack:
  # نام پک‌های قبلی خودتان را اینجا نگه دارید
  - ArvanRoleplayProps_RP.zip
```

فایل `resource_packs.example.yml` فقط نمونه است و PocketMine آن را خودکار نمی‌خواند. هیچ فایل `.key` لازم نیست؛ پک رمزگذاری نشده است. اگر تنظیمات ندارید، نمونه را با نام `resource_packs.yml` در همان پوشه ذخیره کنید.

6. سرور را روشن کنید. در لاگ باید Customies و ArvanRoleplayProps بدون خطا بارگذاری شوند.
7. از بازی خارج شوید و دوباره به سرور وصل شوید و دانلود ریسورس‌پک را قبول کنید. نسخهٔ Bedrock کلاینت باید با پروتکل PocketMine شما سازگار باشد.

## قرار دادن مدل‌ها

با اکانت OP یا مجوز `arvanprops.admin` داخل بازی اجرا کنید:

```text
/arvanprops spawn pump
/arvanprops spawn ammo
/arvanprops remove
```

- مدل دقیقاً در جای پا و با جهت نگاه افقی شما قرار می‌گیرد؛ روی محل موردنظر بایستید و بعد از دستور چند قدم کنار بروید.
- `remove` فقط **نزدیک‌ترین مدل همین پلاگین تا فاصلهٔ ۶ بلوک** را حذف می‌کند؛ مدل‌های دیگر یا موجودات معمولی را حذف نمی‌کند.
- مدل‌ها موجودیت نمایشی هستند، نه بلاک یا آیتم. بی‌وزن و مقاوم به ضربه‌اند و با ذخیرهٔ عادی چانک ذخیره می‌شوند.
- برای باقی ماندن مدل‌ها، فایل دنیا را ذخیره و سرور را عادی خاموش کنید؛ پلاگین و Customies باید هنگام راه‌اندازی بعدی نیز نصب باشند. حذف پلاگین قبل از بارگذاری دنیا می‌تواند باعث از دست رفتن موجودیت‌های سفارشی شود.
- از `/summon` برای این بسته در PocketMine استفاده نکنید؛ دستور ساخت آن‌ها همین `/arvanprops` است.

## انیمیشن‌های خودکار

- پمپ: چشمک چراغ وضعیت، حرکت نقطهٔ روشن روی LED و حرکت نمایشی نوبتی چهار نازل. چرخه‌ها ۲٫۴ و ۶ ثانیه هستند.
- جعبه: چرخهٔ ۶ ثانیه‌ای باز و بسته شدن در با مکث و حرکت نرم.
- انیمیشن‌ها روی کلاینت اجرا می‌شوند؛ برای حرکت نمایشی نیازی به ارسال مداوم پکت از سرور نیست. فاز چرخه ممکن است بین بازیکنان متفاوت باشد.

تمام انیمیشن‌های قبلی، از جمله `open` و `close` جداگانهٔ جعبه، در ریسورس‌پک حفظ شده‌اند. برای حالت همیشه‌باز، در فایل `entity/field_open_ammo_case.entity.json` داخل پک، مقدار `scripts.animate` را `[]` کنید. برای غیرفعال کردن حرکت نازل‌ها و نگه‌داشتن چراغ‌ها، `scripts.animate` پمپ را به `["idle"]` تغییر دهید. پس از تغییر پک، نسخهٔ header و module در manifest را افزایش دهید، ZIP را دوباره بسازید و سرور را ری‌استارت کنید تا کلاینت نسخهٔ جدید بگیرد. این پلاگین فعلاً کلید تعاملی باز/بسته‌کردن ندارد.

## مشخصات برای اتصال به پلاگین دیگر

| مدل | شناسهٔ شبکهٔ Customies | هندسه |
| --- | --- | --- |
| پمپ | `arvan:rp_digital_pump` | `geometry.nova_digital_pump` |
| جعبه | `arvan:rp_ammo_case` | `geometry.field_open_ammo_case` |

شناسه‌های ریسورس و پلاگین دقیقاً مطابق هم‌اند. اگر این شناسه‌ها را در پلاگین خود ثبت می‌کنید، هم‌زمان پلاگین نمونهٔ ArvanRoleplayProps را فعال نکنید؛ هر شناسه فقط یک بار ثبت شود. UUID پک با پک‌های قبلی همین مخزن متفاوت است و هیچ موجودیت وانیلا را جایگزین نمی‌کند.

## محدودیت‌ها و عیب‌یابی

- این‌ها مدل‌های **تزئینی رول‌پلی** هستند؛ سیستم سوخت، پرداخت، موجودی جعبه، شلیک یا اسلحهٔ کاربردی ندارند.
- رنگ روشن LED به معنای نورپردازی واقعی محیط نیست؛ درخشش واقعی به متریال/شیدر کلاینت وابسته است.
- PocketMine رفتارپک‌های وانیلا را مانند Bedrock Dedicated Server اجرا نمی‌کند؛ به همین دلیل برای ثبت و ساخت مدل‌ها PHAR و Customies ارائه/استفاده شده است.
- اگر دستور وجود ندارد: لاگ بارگذاری پلاگین، نسخهٔ API و وابستگی Customies را بررسی کنید.
- اگر مدل نامرئی است: فعال بودن پک در resource_stack، پذیرفتن دانلود، عدم ثبت تکراری شناسه و خطاهای Content Log کلاینت را بررسی کنید.
- تست زنده روی سرور PocketMine و کلاینت Bedrock در این محیط انجام نشده است. ساختار و ارجاعات ریسورس، انیمیشن‌ها، سینتکس PHP و محتوای PHAR بررسی شده‌اند؛ سازگاری نهایی با ترکیب نسخه‌های واقعی سرور/کلاینت شما باید در یک سرور تست بررسی شود.

## بازسازی از سورس مخزن

از پوشهٔ `assets/roleplay_props_bedrock`:

```sh
php -d phar.readonly=0 build_phar.php
python -m pip install 'Pillow>=10.1,<13'
python build.py
```

فایل‌های هندسه، تکسچر و انیمیشن از پوشهٔ همسایهٔ `roleplay_props` خوانده می‌شوند. سورس پلاگین به PHP 8.1 یا جدیدتر نیاز دارد. فایل `SHA256SUMS.txt` برای بررسی صحت خروجی‌ها است.

# مدل‌های رول‌پلی — Blockbench

دو مدل مستقل و قابل ویرایش؛ فقط خود پمپ و جعبه، بدون ساختمان پمپ‌بنزین یا صحنهٔ اضافی.

نوشته‌های برند روی پمپ و جلوی جعبه **ARVAN GAMING** است. نوشته‌های درِ جعبه حذف شده‌اند و صفحهٔ داخلی آن بدون متن است. برای سازگاری با نسخهٔ قبلی، نام فایل‌ها و شناسه‌های مدل تغییر نکرده‌اند.

## فایل اصلی هر مدل

- `nova_digital_pump/nova_digital_pump.bbmodel` — پمپ مدرن سفید و گرافیتی با نورهای فیروزه‌ای، صفحهٔ لمسی با رابط گرافیکی، نمایشگر مبلغ و حجم، کارت‌خوان و NFC، چهار نازل رنگی، چهار شلنگ و پنل سرویس.
- `field_open_ammo_case/field_open_ammo_case.bbmodel` — جعبهٔ سبز زیتونی با لولا، قفل و دستگیره، درِ باز ۱۰۵ درجه، فوم داخلی، یک اسلحهٔ بلند و یک کلت تزئینی و چهار خشاب یدک. مدل‌های اسلحه صرفاً وسایل بصری بازی هستند.

در Blockbench از **File → Open Model** فایل `.bbmodel` را باز کنید. تکسچر ۵۱۲×۵۱۲ داخل فایل ذخیره شده و کنار آن نیز PNG مستقل قرار دارد؛ نیازی به پیدا کردن دستی تکسچر نیست. قسمت‌ها نام‌گذاری و گروه‌بندی شده‌اند و هر مکعب جداگانه قابل ویرایش است.

## درِ متحرک جعبه

در در حالت پیش‌فرض باز است. گروه `lid_hinge` محور چرخش را دقیقاً روی لولای عقب دارد. چرخش X آن ۱۰۵ درجه است؛ برای بسته شدن، آن را صفر کنید. در تب Animate انیمیشن `animation.field_open_ammo_case.close` در یک ثانیه در را از حالت باز به بسته می‌برد. برای دیدن مدل باز، انیمیشن را متوقف یا زمان آن را صفر کنید.

## خروجی‌ها و پیش‌نمایش

- `.bbmodel`: پروژهٔ اصلی Blockbench با تکسچر توکار.
- `.png`: تکسچر مستقل؛ `preview.png` تصویر رندرشدهٔ خود هندسه است، نه تصویر مفهومی.
- `.geo.json`: هندسهٔ Bedrock با گروه‌بندی مدل.
- `.animation.json`: انیمیشن بسته‌شدن درِ جعبه برای Bedrock.
- `PREVIEW.jpg`: پیش‌نمایش هر دو مدل.

ابعاد تقریبی پمپ: ارتفاع ۳۶٫۸ واحد Blockbench؛ هر ۱۶ واحد معادل یک بلوک در مقیاس معمول Bedrock. بدنهٔ جعبه ۳۰×۱۶ واحد و ارتفاع بدنه حدود ۷ واحد است. می‌توانید هر دو را با گروه `root` مقیاس‌دهی کنید.

**محدودیت روشن:** این ZIP بستهٔ مدل‌سازی است، نه پلاگین، آیتم قابل اسپاون یا ریسورس‌پک نصب‌شدنی. برای استفاده در سرور باید مدل‌ها به سیستم آیتم/موجودیت سرورتان متصل شوند. صفحهٔ لمسی، کارت‌خوان و اسلحه‌ها تزئینی هستند و منطق تعاملی ندارند. نوارهای LED تکسچر روشن دارند؛ نور محیطی یا درخشش واقعی به متریال/شیدر موتور مقصد وابسته است.

## بازتولید و بررسی

Python 3.10 یا جدیدتر لازم است:

```sh
python -m pip install -r requirements.txt
python generate.py
```

اسکریپت، مدل‌ها، تکسچرها، خروجی هندسه، پیش‌نمایش‌ها و ZIP را بازتولید و شناسه‌ها، ارجاع گروه‌ها، محدودهٔ UV، تکسچر توکار، تعداد مکعب‌ها و صحت ZIP را بررسی می‌کند. رندر پیش‌نمایش مستقیماً از مکعب‌ها، چرخش‌ها و تکسچر فایل ساخته می‌شود.

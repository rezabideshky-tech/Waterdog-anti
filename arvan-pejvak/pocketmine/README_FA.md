# افزونهٔ PocketMine آروان پژواک

این پلاگین پل میان PocketMine-MP و سرویس کنترل آروان پژواک است؛ **صوت را داخل PocketMine حمل نمی‌کند**. صدای کم‌تأخیر با WebRTC/LiveKit جابه‌جا می‌شود تا ترافیک صدا حلقهٔ اصلی سرور بازی را کند نکند.

## نصب توسعه‌ای

1. PocketMine-MP API 5 و افزونهٔ DevTools را اجرا کن.
2. پوشهٔ `pocketmine/` را با نام `ArvanPejvak` در `plugins/` قرار بده.
3. سرور را یک بار اجرا کن تا `plugins/ArvanPejvak/config.yml` ساخته شود.
4. `gateway-url`، `shared-secret` و `server-id` را تنظیم کن. secret باید با `CONTROL_SHARED_SECRET` در gateway یکی باشد؛ آن را عمومی یا commit نکن.
5. سرور را دوباره راه‌اندازی کن. بازیکن برای گرفتن کد یک‌بارمصرف می‌زند:

```text
/pejvak code
```

کد را در اپ آروان پژواک وارد می‌کند. کد کوتاه‌عمر است و فقط یک بار پذیرفته می‌شود.

## ساختار ارتباط

- این پلاگین هر ثانیه یک snapshot سبک از XUID/UUID، نام، دنیا و مختصات بازیکنان را به gateway می‌فرستد؛ درخواست‌ها در AsyncPool انجام می‌شوند، نه روی تیک اصلی.
- دنیا در مسیر موبایل با SHA-256 نمایش داده می‌شود تا نام پوشهٔ دنیای خصوصی افشا نشود.
- gateway همسایه‌ها را در همان دنیا و در شعاع تنظیم‌شده پیدا می‌کند و به LiveKit می‌گوید مشترک‌شدن با صدای کدام بازیکن مجاز باشد.
- کدهای اتصال از gateway گرفته می‌شوند تا به یک XUID/UUID داخل بازی متصل و یک‌بارمصرف باشند.

## ساخت PHAR

برای ساخت PHAR مستقل با PHP دارای افزونهٔ Phar اجرا کن: `php -d phar.readonly=0 build-phar.php`. همچنین CI در GitHub پس از موفقیت lint، artifact `ArvanPejvak-PocketMine-PHAR` می‌سازد. PHAR را پیش از استفادهٔ عمومی روی نسخهٔ واقعی PocketMine-MP staging تست کن.

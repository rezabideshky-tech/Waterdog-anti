# اپ همراه سرور آروان گیمینگ — Bedrock / PocketMine

اپ اندرویدی فارسی با بازطراحی روشنِ بنفش‌وسفید، کارت‌های نرم و سایه‌دار، ناوبری شناور، ورود مرحله‌ای صفحه‌ها و دکمه‌های ضربه‌ای/موجی. پروژهٔ AIDE در این پوشه است و ماژول Gradle در `android-build/arvan-gaming` همان سورس را برای ساخت APK می‌خواند.

## قابلیت‌های پیاده‌سازی‌شده

- صفحهٔ خانه با سربرگ بنفش، اسلایدر چهار‌بخشیِ فلش‌دار و نقطه‌دار، پیش‌نمایش گوشی مایل و قابل‌تعامل؛ سبک چیدمان مطابق تصاویر مرجع.
- کارت سرور با دکمهٔ بررسی دوباره، کپی آدرس، خبر مهم بعدی و شمارش معکوس نزدیک‌ترین رویداد.
- جستجوی زنده در صفحه‌های اپ و محتوای واقعی فید؛ پیشنهادهای سریع برای راهنما، رویدادها، خبرها و پروفایل.
- راهنمای مرحله‌ای اضافه‌کردن سرور در Minecraft Bedrock موبایل.
- صفحات رویدادها، اخبار/نظرسنجی، پروفایل پلیر و انجمن/دعوت دوستان.
- دکمهٔ یادآور، از طریق بازکردن فرم رویداد در تقویم گوشی.
- نشان‌های محلی داخل اپ و اشتراک‌گذاری کارت پلیر/دعوت.
- صفحه‌ها و دکمه‌ها انیمیشن ورود و لمس دارند.

## دادهٔ واقعی؛ بدون آمار ساختگی

- وضعیت و شمار پلیرها با **RakNet/Bedrock unconnected ping واقعی** از آدرس تنظیم‌شده پرسیده می‌شود.
- فقط پاسخ معتبر Bedrock می‌تواند وضعیت را «آنلاین» و تعداد بازیکن را نشان دهد. timeout یا پاسخ نامعتبر به معنی آفلاین قطعی نیست؛ اپ آن را «بی‌پاسخ/نامشخص» می‌گذارد و عدد جعلی مثل صفر نشان نمی‌دهد.
- نام میزبان و پورت فعلاً عمداً خالی‌اند؛ تا وقتی آدرس رسمی سرور از مدیریت دریافت نشده، دکمهٔ کپی فعال نیست.
- نسخه‌های سازگار، خبرها، قوانین، رویدادها، نتایج، نظرسنجی‌ها و لینک کانال‌ها فقط از فید HTTPS یا تنظیمات تأییدشده می‌آیند. چون آدرس/API رسمی در اختیار پروژه نیست، صفحات برای این داده‌ها حالت خالیِ روشن دارند، نه خبر یا مسابقهٔ خیالی.
- رتبه، زمان بازی و آمار پروفایل فقط پس از پاسخ API با bearer token نمایش داده می‌شوند. اتصال حساب از کد یک‌بارمصرف و فرمان داخل بازی طراحی شده و رمز Microsoft/Xbox از کاربر خواسته نمی‌شود. token فقط در حافظهٔ همان اجرای اپ می‌ماند.

## تنظیم آدرس Bedrock

در `src/ir/arvangaming/app/ArvanGamingConfig.java`، پس از تأیید مدیر سرور:

```java
static final String SERVER_HOST = "play.example.net";
static final int SERVER_PORT = 19132;
```

آدرس و پورت بالا صرفاً **نمونهٔ قالب** هستند؛ با مقدار واقعی سرور جایگزینشان کنید. برای نمایش نسخه‌ها، لینک‌ها و دادهٔ زندهٔ رویدادها، `SUPPORTED_CLIENT_VERSIONS` و لینک‌های رسمی را فقط با مقادیر تأییدشده پر کنید.

## قرارداد API اختیاری

`API_BASE_URL` باید HTTPS باشد. اپ این مسیرها را می‌خواند:

```text
GET  /v1/app/public
POST /v1/link/start
GET  /v1/link/status?sessionId=...
GET  /v1/profile                 Authorization: Bearer <token>
POST /v1/polls/{pollId}/vote
POST /v1/reports
```

پاسخ عمومی نمونه:

```json
{
  "server": {
    "address": "دامنهٔ واقعی",
    "port": 19132,
    "supportedVersions": ["نسخهٔ تأییدشده"],
    "inviteCode": ""
  },
  "news": [],
  "events": [],
  "polls": [],
  "rules": [],
  "links": {
    "support": "https://...",
    "telegram": "https://...",
    "discord": "https://...",
    "instagram": "https://...",
    "community": "https://..."
  }
}
```

`events` می‌تواند `title`, `description`, `startsAt` (میلی‌ثانیهٔ Unix), `registrationUrl`, `result` و `winners` داشته باشد. پاسخ `/v1/link/start` باید `code`, `sessionId`, `expiresInSeconds` و در صورت نیاز `command` برگرداند. افزونهٔ سمت PocketMine باید کد یک‌بارمصرف کوتاه‌عمر را با XUID/UUID معتبر پیوند دهد و پس از تأیید، فقط همان نشست را `linked` کند. این backend در این APK ادعا نشده و تا نصب/تنظیم آن آمار پروفایل غیرفعال می‌ماند.

## ساخت APK

GitHub Actions پس از تغییر این پوشه اجرا می‌شود. از صفحهٔ Actions، artifact به نام `ArvanGaming-debug-apk` را دانلود کنید؛ ZIP شامل `arvan-gaming-debug.apk` است و ۳۰ روز نگه‌داری می‌شود.

ساخت دستی با JDK 17 و Android SDK:

```bash
gradle --no-daemon -p android-build :arvan-gaming:assembleDebug
```

APK با کلید debug امضا می‌شود؛ برای Google Play یا توزیع رسمی باید با کلید release مستقل امضا شود. حداقل اندروید 5.0 (API 21) است.
